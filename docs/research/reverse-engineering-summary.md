# 夸克扫描王「扫描 + AI 矫正」逆向研究：设计层面摘要

> 日期：2026-10-20（北京时间）。基于对夸克扫描王 Android 官方安装包（10.13.0.455）的 **静态分析** 与公开资料；没有运行 App、没有抓流量、没有解码或提取任何模型和脚本。
> 本文件是公开仓库用的 **设计层面摘要**：只保留对我们设计有用的结论和数值量级，去掉了反编译得到的内部类名、方法名、配置键、文件路径等实现细节。
> 标注：【实测】=安装包或公开文档中直接看到；【推断】=据证据推出、未在运行时验证；【无法确认】=没有证据。

## 1. 结论
1. **端侧模型很小。** 安装包带 MNN 推理引擎和阿里的端侧计算容器 Walle（论文见 OSDI'22）。随包的找边/分类模型只有约 0.9 / 1.7 / 2.0 MB，另有一个约 3.3 MB 的文字区域检测模型。【实测：大小】模型是受保护格式，输入输出形状【无法确认】。
2. **离线流水线三步 + 一个增强：** 找文档 → 摆正/展平 → 边缘吸附，再加一个可离线的滤镜/增强步骤；增强步骤会传入 1–5 档的机型分级。【实测：任务结构；推断：每步作用】
3. **几何矫正是「点回归 + 薄板样条（TPS）」：** 平纸回归 4 个角点；书页回归 6 个点（四角 + 两条弯边上的点），再做 TPS 展平；检测模式只有「四点 / 左右 / 上下」三种。比 UVDoc 这类密集网格模型小一个数量级。【实测：名称；推断：做法】
4. **云端增强 = 上传压缩图 → 服务端处理 → 下载结果。** 默认上传 JPEG 质量 0.85–0.88、≤ 1.5 MB、上限 16 MP 或长边 1500；上传超时默认 15 秒，没网直接报错。【实测：默认值】
5. **只有少数滤镜离线可用：** 「增强」「省墨」和两个照片风格滤镜标为离线可用；默认的「智能」（AI 滤镜）不在其中，推断需要云端。用户吐槽的「涂抹感」最可能出自这一档。【实测：配置；推断：含义】
6. **离线效果差距只有官方口径：** 「模型缩小 100 倍，加传统算法效果保持 95%，约 2 秒」（2022），没有公开测试集。

## 2. 离线模式流水线（重建）
```
相机流 → 实时文档检测（独立的小任务，可走 GPU）
       → 四边形动画：旧框向新框 smoothstep 插值；有「稳定」标志
       → 倾斜提示：默认阈值 18°；稳定判定约需连续 2 次检测
拍照
 → 找文档：4 点检测 / 6 点检测 / 文档分类（三个 1–2 MB 模型）
 → 摆正/展平：分类 → 四点或六点回归 → 校验 → TPS / 六点展平
 → 边缘吸附：把点吸附到真实边缘（推断）
 → 书本模式：拆页（至少部分在云端修正）
 → 离线增强（filter_type, 机型分级）
导出（图片 PDF 在本地拼接；「标准 PDF / 转 Office」依赖云端）
```

## 3. 可迁移的「又准又快」做法
1. **级联而不是一个大模型：** 极小的预览检测 + 拍后 1–2 MB 的点回归 + 经典边缘吸附 + TPS 几何重采样。
2. **先分类再选路：** 平纸根本不跑展平。
3. **按机型分级：** 依据内存、CPU 频率和核数分 1–5 档，用于选择模型或分辨率。
4. **算法输入不用全分辨率：** 4–16 MP 量级，几何参数映射回原图再重采样。
5. **空闲时预热模型**，首屏不加载大模型。
6. **默认本地，云端失败回落本地。**

## 4. 原图 / 增强 / 智能
- 滤镜顺序：原图 · 智能（默认）· 增强 · 去杂质 · 证件票据 · 打印 · 黑白 · 省墨 · 增亮。
- **原图**：推断只做几何。**增强**：可离线，推断是背景/光照均衡 + 对比度锐化。**智能**：AI 滤镜 + 自动选风格（单据「真实呈现」/ 文件「黑白分明」），需要云端。**黑白/增亮/灰度**：推断是确定性的经典算法。

## 5. 对 LocalScan 的启示（iOS）
```
① 预览：VNDetectDocumentSegmentationRequest → 时域平滑 → 稳定判定（连续 N=3–5 帧角点位移 < 1–2% 对角线，倾斜 < 18°）→ 自动拍
② 原图保留（HEIC）+ 工作图（长边 1600–2048 / ≤ 6 MP）
③ 分类（≤ 2 MB）：平纸 / 书页单页 / 双页 / 卡证 / 屏幕
④ 几何：平纸 → 边缘吸附 → CIPerspectiveCorrection；书页 → 6 点回归（≤ 2 MB）→ TPS → Metal 重采样；残余弯曲大时才用 UVDoc（FP16 约 15 MB，输入 488×712，输出 45×31 网格）
⑤ 外观：原图只做几何；增强用确定性经典算法；黑白在增强上做自适应阈值；AI 去阴影/增强为本地显式开关，不生成笔画
⑥ 输出：HEIC/JPEG（质量 0.80–0.88）；PDF（PDFKit，可选 Vision OCR 隐藏文字层）
```
- 模型目标：分类 ≤ 2 MB、点回归 ≤ 2 MB、UVDoc ≤ 15 MB、光照估计 ≤ 5 MB，随包合计 ≤ 25 MB；Core ML FP16 或 INT8，`computeUnits = .all`；重采样和色彩处理放在 Metal / Core Image。
- 机型分 3 档：A14 及以下、A15–A16、A17 及以上；低档跳过 UVDoc 或降分辨率。
- 默认用「原图」或「增强（经典）」，不默认 AI；增强必须确定性，CER 不劣于原图。
